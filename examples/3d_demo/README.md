# 3D demo

`3d_demo.scene` — сцена с `Scene3D: 1`: пол, три куба и сфера, перспективная камера
(`CamPersp: 1`, `CamFov: 55`), тени от солнца. Скопируйте в `assets/scenes/` своего проекта
и откройте двойным кликом: редактор сам включит 3D-вид.

Управление в 3D-сцене: ПКМ — осмотреться (+WASDQE — полёт), колесо — толчок вперёд/назад,
ЛКМ — выделение и гизмо, F — навестись на выбранное, NUMPAD 1/2/3/4/5/7 — виды.
