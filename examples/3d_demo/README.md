# 3D demo

`3d_demo.scene` — сцена с `Scene3D: 1`: пол, три куба и сфера, зона-триггер, перспективная
камера (`CamPersp: 1`, `CamFov: 55`), тени от солнца. Скопируйте в `assets/scenes/` своего
проекта и откройте двойным кликом: редактор сам включит 3D-вид.

Что внутри:

| Объект | Что показывает |
|---|---|
| `Ground` | Plane-меш + Collider (3D) — плоский пол, по нему считается «пол» |
| `Cube Bouncing` | Rigidbody (3D) + скрипт `assets/scripts/bounce3d.cpp`: гравитация, `Raycast3D` вниз, `SetVelocity3D` при контакте, `OnCollisionEnter` в консоль |
| `Cube Static` | статичный короб без Rigidbody — на него можно опереться |
| `Cube Metal` | свой 3D-шейдер `assets/shaders/metal3d.frag` (френель + блик + тень) |
| `Sphere` | сфера-коллайдер, катится (`Rb3Velocity 0 0 -120`) |
| `Trigger Zone` | `Col3Trigger: 1` — события без расталкивания, рисуется голубым каркасом |
| `Main Camera` | `CamPersp: 1` — Game-view смотрит через неё, поза из `Pos3`/`Rot3` |

Зависимости сцены (лежат в этом же репо): `assets/scripts/bounce3d.cpp` и
`assets/shaders/metal3d.frag`. Если переносите сцену в свой проект — заберите и их, либо
очистите поля `ScriptPath` / `MeshShader` в инспекторе.

Управление в 3D-сцене: ПКМ — осмотреться (+WASDQE — полёт, Shift — быстрее, Ctrl — медленнее),
колесо — толчок вперёд/назад, СКМ или Hand (Q) + ЛКМ — пан, ЛКМ — выделение и гизмо,
F — навестись на выбранное, NUMPAD 1/2/3/4/5/7 — виды, 6 — перспектива, компас в углу — то же
мышью.
