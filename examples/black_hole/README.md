# Демо «Чёрная дыра»

Показывает три вещи сразу: шейдерный API, скриптовый API и иерархию.

## Что где
| Файл | Роль |
|---|---|
| `black_hole.frag` | шейдер аккреционного диска (только фрагмент — вертекс даёт движок) |
| `orbit_planet.cpp` | скрипт орбиты: `Script`, `WorldPosition()`, `SetWorldPosition()`, `LookAt()` |
| `black_hole.scene` | сцена: камера, дыра, две планеты, луна-ребёнок, звёзды |

## Как запустить
Файлы уже продублированы в `assets/` движка. Просто:

1. Запустить редактор (`./build/Astra`).
2. File ▸ Open Scene... → `assets/scenes/black_hole.scene`.
3. Нажать Play.

## Что под капотом
- **Диск вращается без единой строки C++** — шейдер сам анимируется через `u_Time`,
  шум даёт `EngineFbm`, цвет — `EnginePalette`.
- **Планеты** — обычный Quad/Circle + скрипт. Радиус орбиты = позиция, выставленная
  в редакторе гизмо. Скрипт не пишет ни одного `#include`: движок подставляет API сам.
- **Луна** — дочерний объект планеты: её не нужно двигать кодом, она следует
  за родителем, как в Unity.
- **Горизонт событий** — триггер-коллайдер: можно повесить `OnDestroy`-звук или
  респавн, не трогая шейдер.
